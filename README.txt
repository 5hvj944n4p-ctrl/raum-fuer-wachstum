# Raum für Wachstum – Demo-Website

Öffne `index.html` im Browser, um die Website lokal anzusehen.

Vor einer Veröffentlichung bitte insbesondere:
- Name, Anschrift, Telefonnummer und E-Mail ersetzen
- echte Qualifikationen und das tatsächliche Leistungsangebot eintragen
- Impressum und Datenschutzerklärung rechtssicher ergänzen
- Beispielbild durch eigene/lizenzierte Bilder ersetzen
- Kontaktformular an einen echten Formular-/E-Mail-Dienst anbinden

Die Datei `website-konzept.png` ist das generierte Beispielbild aus dem Entwurf.
